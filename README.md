# Yildiz · Página web

Sitio estático (HTML y CSS) de la tienda de joyería **Yildiz**, construido según su guía de marca.

Abre `index.html` en el navegador para verlo.

- `index.html`: estructura de la página
- `styles.css`: estilos (colores de marca como variables en `:root`)
- `img/`: logotipo, isotipo y fotografías
